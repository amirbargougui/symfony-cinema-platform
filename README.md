# Symfony Web Application

## Description
Web application built with Symfony demonstrating backend development using the MVC architecture.

## Features
- User authentication
- CRUD operations
- Database integration
- Role-based access control

## Tech Stack
- PHP (Symfony)
- MySQL
- Twig
- Doctrine ORM

## How to Run
1. Clone the repository  
2. Configure the `.env` file  
3. Run database migrations  
4. Start the Symfony server
